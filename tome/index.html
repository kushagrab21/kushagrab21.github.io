    How this run was made ↓

    Replayed from records: the reading, the topics, the plan and the building. Worked out live in your browser: the ball's flight, the marking and your own throws.

    GPT-5 is an AI model that reads text and writes text back; Tome pays for each request. Fixed code is ordinary code: same input, same result, every time. The voice service turns written lines into speech.

    Three values of gravity appear, and all are real: Tome's simulation uses g = 9.81, its practice question uses g = 10 so the sums come out round (40 m), and my page uses g = 9.8 (40.8 m).

    I checked the physics with separate code that shares nothing with Tome. The flight time and range are right, 45° goes farthest, angles that add up to 90° land in the same place, and the practice answer is right.
